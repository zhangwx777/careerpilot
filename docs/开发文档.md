## 3. 数据模型

5 张表，关系为 company 1—n position 1—n application 1—n (timeline_node / interview_intel)。

### company（公司）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | int PK | |
| name | str, unique | 公司名 |
| industry | str, 可空 | 行业 |
| created_at | datetime | |

### position（岗位）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | int PK | |
| company_id | FK→company, cascade | |
| title | str | 岗位名 |
| jd_text | text, 可空 | JD 原文 |
| created_at | datetime | |

### application（投递记录）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | int PK | |
| position_id | FK→position, cascade | |
| status | enum | 已投递/笔试/一面/二面/三面/HR面/offer/挂 |
| applied_at | datetime, 可空 | 投递时间 |
| note | text, 可空 | 备注 |
| created_at | datetime | |

### timeline_node（时间线节点）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | int PK | |
| application_id | FK→application, cascade | |
| node_type | enum | 网申截止/笔试/一面/二面/三面/HR面/其他 |
| scheduled_at | datetime, 可空 | 节点时间 |
| status | enum | 待处理/已完成/已错过/已取消 |

| created_at | datetime | |

### interview_intel（面经情报）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | int PK | |
| application_id | FK→application, cascade | |

枚举定义集中在 `app/models.py` 顶部常量（`APPLICATION_STATUS` / `NODE_TYPE` / `NODE_STATUS`）。

## 4. 多模型 provider 层

### 设计
- `registry.py`：`PROVIDERS` 字典把 provider（anthropic/openai/deepseek/qwen）映射到 `{api_key, api_base}`。key 与 base_url 均来自 `.env`。base_url 留空则为 `None`（走 LiteLLM 官方默认），Qwen 留空时兜底 DashScope 兼容端点。
- `provider.py`：`chat(messages, task, model)` 统一入口。`task` 为 `"parse"`（便宜快）或 `"reason"`（能力强），映射到 `.env` 中的 `MODEL_PARSE` / `MODEL_REASON`。可用 `model` 显式覆盖。调用前用 `has_key()` 校验，无 key 抛错。

### 模型命名
LiteLLM 格式 `provider/model`，如 `deepseek/deepseek-chat`、`anthropic/claude-sonnet-4-20250514`、`openai/gpt-4o-mini`、`qwen/qwen-plus`。`provider_of()` 按 `/` 前缀推断厂商。

### 任务→模型映射（默认，可在 .env 改）
- `MODEL_PARSE=deepseek/deepseek-chat`
- `MODEL_REASON=anthropic/claude-sonnet-4-20250514`

## 5. 配置说明（.env）

```
DATABASE_URL=postgresql+psycopg://<user>:<pwd>@127.0.0.1:5432/qiuzhao
ANTHROPIC_API_KEY= / OPENAI_API_KEY= / DEEPSEEK_API_KEY= / DASHSCOPE_API_KEY=
ANTHROPIC_BASE_URL= / OPENAI_BASE_URL= / DEEPSEEK_BASE_URL= / DASHSCOPE_BASE_URL=
MODEL_PARSE= / MODEL_REASON=
```

`.env` 优先于系统环境变量（`config.py` 中定制了 settings 源顺序）。`.env` 已被 `.gitignore` 忽略，不入库。

## 6. 本地运行

```bash
cd backend
python -m venv .venv
.venv/Scripts/python.exe -m pip install -e .

# 复制 .env.example 为 .env 并填值
.venv/Scripts/python.exe -m scripts.init_db      # 建表
.venv/Scripts/python.exe -m scripts.smoke_llm    # 测模型连通（需已填 key）
.venv/Scripts/python.exe -m uvicorn app.main:app --port 8000
```

验证：`GET http://127.0.0.1:8000/health` 返回 `{"status":"ok","db":true}`。

## 8. LangGraph 使用规划（第 3 期起）

仅在控制流本身需要图编排处使用，非装饰：
- 半自动解析的人工介入：`interrupt()` + Postgres checkpointer 实现暂停/恢复。
- 面经聚合：并行 fan-out → 汇聚 → 冲突消解 → 置信度条件循环 → Reflection 自校正 → 冲突时 interrupt 人工裁决。
