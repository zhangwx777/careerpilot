# 交接文档

供后续协作（含在其他环境如 codex 上接手）快速了解项目状态。

## 1. 项目概览

个人秋招求职辅助系统，专注信息聚合与决策辅助（不做自动投递）。两大方向：A 进度指挥中心、B 定向面经情报。详见 `docs/PRD.md`、`docs/开发文档.md`、`docs/工作计划.md`。

- 仓库：https://github.com/zhangwx777/qiuzhao-agent
- 本地路径：`C:\qiuzhao-agent`
- 主分支：main

## 2. 当前进度

分 5 期开发，**第 1 期已完成并推送**。

| 期 | 内容 | 状态 |
|---|---|---|
| 1 | 项目骨架 + 数据模型 + 多模型 provider 层 | ✅ 完成 |
| 2 | 投递管理 CRUD + 前端基础界面 | 待开始 |
| 3 | 半自动解析 + HITL + 时间线/冲突检测 | 待开始 |
| 4 | 面经聚合图（并行/冲突消解/reflection/置信度） | 待开始 |
| 5 | 备战 Planner + 每日巡检 | 待开始 |

## 3. 第 1 期已交付内容

- 后端骨架：FastAPI + `/health`（含连库检查）。
- 数据库：PostgreSQL 5 张表已建（company / position / application / timeline_node / interview_intel），本地 PG 18 实例，数据库名 `qiuzhao`，使用专用低权限账号连接。
- 多模型 provider 层：LiteLLM 统一 Claude / OpenAI / DeepSeek / Qwen；key 与 base_url 均由 `.env` 配置；`.env` 优先于系统环境变量。
- 脚本：`scripts/init_db.py` 建表、`scripts/smoke_llm.py` 测模型连通。
- 文档：README + PRD + 开发文档 + 工作计划 + 本交接文档。

## 4. 环境状态

- Python 3.12，虚拟环境在 `backend/.venv`，依赖已装（`pip install -e .`）。
- Node.js 已具备（前端第 2 期用）。
- PostgreSQL 18 本地实例运行中，`qiuzhao` 库与 5 张表已就绪。
- `.env` 由使用者自行配置（含数据库连接串与各模型 key），不入库。

## 5. 待验证事项

- **模型 provider 层端到端未验证**：截至第 1 期结束，`.env` 中模型 key 为空，`smoke_llm.py` 仅验证过"无 key 优雅跳过"的逻辑，尚未真正调通任一家模型。配好 key 后运行 `python -m scripts.smoke_llm` 确认。

## 6. 数据同步说明

- 代码通过 git 同步；数据库数据不入库，在本地 PG 实例中。
- 换机时：代码 `git clone`；`.env` 需重建；数据用 `pg_dump`/`psql` 手动导出导入，或后续改用云数据库（仅改 `.env` 连接串，代码不动）。
